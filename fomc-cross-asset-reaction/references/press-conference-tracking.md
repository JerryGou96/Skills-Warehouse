1. Read `${RESEARCH_VAULT_ROOT}/agents/macro/FOMC 追踪.md` and `${RESEARCH_VAULT_ROOT}/agents/macro/memory/fomc/README.md` before analysis to locate the canonical meeting archive and prior stance. Treat this branch as the existing destination, not a request to create a Git branch or a second copy of the archive.
2. Fetch the official meeting calendar to discover press-conference materials. For a conference PDF, try `https://www.federalreserve.gov/mediacenter/files/FOMCpresconfYYYYMMDD.pdf`; count it as read only after extracting readable text and verifying its date and scope. Distinguish opening remarks from a full Q&A transcript.
3. Search `"<chair> press conference <Month day year> Fed inflation live"` for contemporaneous reporting. Fetch CNBC’s `https://www.cnbc.com/YYYY/MM/DD/fed-meeting-today-live-updates.html` when discovered, and cross-check substantive answers against another retrieved live report such as the New York Times. Inspect the body for actual post-start questions and answers; a live-blog title can conceal only premeeting commentary.
4. Record the retrieval time and latest verifiable coverage cutoff. Summarize only the available portion if the conference is ongoing or the transcript is incomplete, so a partial summary does not become a final record.
5. Separate chair quotations, reporter paraphrases, outside economists’ opinions, and your interpretation. Extract the rationale for the decision, inflation and employment priorities, policy restrictiveness, next-action conditions, productivity and financial-conditions arguments, and communication changes. Mark a question unanswered when the retrieved answer does not resolve it; do not substitute market-implied probabilities for an explicit policy promise.
6. Read the existing dated meeting file and template under `agents/macro/memory/fomc/` before writing. Append newly verified conference evidence to the same meeting file, preserving earlier statement-stage conclusions and timestamps. Track official statement, implementation note, SEP, opening remarks, full Q&A, minutes, and market windows with separate completeness labels.
7. Update the branch’s cross-meeting timeline with prior wording, new wording, and the resulting interpretation. Keep inflation concern, employment risk, action timing, balance-sheet policy, and communication commitments separate, because a slower tightening pace need not mean a dovish policy reversal.
8. When subsequent PCE, employment, or other data tests the meeting thesis, save a dated research note and append a linked post-meeting validation section. Label the information as released after the meeting rather than rewriting what was known during the conference.
9. Use vault-relative wikilinks such as `[[agents/macro/memory/fomc/YYYY-MM-DD|Meeting date]]` instead of ambiguous date-only or README links. Maintain navigation from the macro README and vault INDEX by merging existing content; check that each new link resolves to an existing Markdown file.
